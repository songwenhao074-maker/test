## 主要问题
1. **保留记忆不等于记忆有用。** 5次满容量birth被跳过，专家9成功保留，purge=0；最终记忆9/15/17/18，reactivation仍为0。在S3首次阶段形成的专家9，于S3_rec2两次验证的候选损失分别比当前在线组合高16.52%和9.42%。这直接否定了“只要留下它就能自然复用获益”的简单解释，但尚不能断言其他专家或其他时点也无收益。
2. **不能只怪guard严格。** 10次选择中9次已决策且全部拒绝，另1次流尾截尾，不能算作拒绝。9次中8次未达到1%损失改善。仅S6_first专家9达到+1.4079%，却因正常guard损失增加2.6805%超过2%而拒绝。放宽guard至多改变这一次已观测决定；不能由此推算改门槛后的完整轨迹。
3. **筛选仍可能漏掉有用记忆，现有日志不足以区分。** 154次reuse到期中79次busy、32次无休眠记忆、33次无匹配、10次选中。代码只验证余弦相似度最高的一个休眠专家。高输入相似度不等于低残差损失，未选中专家没有同期预测证据。尤其S5回归没有匹配，不足以证明对应记忆无效。
4. **冻结专家与持续学习的组合可能不再适配，这是待检验解释。** 主干及73维残差输入构造固定，不能称为“主干表示漂移”；四个通用专家和路由继续更新，而已接受专家及其路由冻结。旧专家加入当前组合的效用可能变化，也可能从未形成稳定业务专长，现有数据尚不能区分。
5. **记忆覆盖有限。** 四次新生接受发生在S3/S5/S6阶段，S6有两次；不是六种业务各有独立专家。满容量保护还阻止了五次新生机会，存在明确代价。
