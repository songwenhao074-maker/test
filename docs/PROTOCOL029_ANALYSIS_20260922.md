## 科学线索：仅供探索，待有效诊断复核

- 相对live损失改善3.11%–7.89%，但五次都同时处于busy且相似度不足，交集是同一批5次，不是10次机会。

作一个明确受限的描述性计算：每个完整窗口允许事后选择“保留live”或“整窗用一个有完整覆盖的休眠专家”，无候选时保留live，九窗口平均AP为0.767217565，比live增加0.000536396，仍低于历史C的0.769551009。这是标签事后选择、忽略切换/验收代价的探索性统计，且依赖未通过门禁的029；不是在线策略，也不是任意窗口内切换、更新专家或改变场景后的性能上界。

因此目前更值得怀疑的是：现有冻结记忆在回归主窗口的额外效用有限，而不只是“有记忆但调度没有用上”。这仍是待复核判断，不应立即同时改调度、阈值和场景。
