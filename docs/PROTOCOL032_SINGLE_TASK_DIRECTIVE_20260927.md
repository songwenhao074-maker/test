## 唯一方法变化
只把D的新生和非阻塞复用中F0正常NLL条件从
`L_candidate <= 1.02 * L_live + 1e-6`
改为
`L_candidate <= L_live + max(0.02 * L_live, 0.01) + 1e-6`。
0.01为平均每正常host-step的自然对数损失容忍额下限；它是新的部署假设和显式放宽，不是数值修复，也不是仅凭历史结果证明的最佳阈值。低NLL区间相当于容许几何平均正常类别概率约1%的相对下降，不等于FPR可任意增长。看到031结果后确定此开发假设，禁止将032作为独立确认试验。
